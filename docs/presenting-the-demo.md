**STOCHASTIC SPM**

**60-Minute Demo — Run of Show**

*AI-Assisted Strategic Portfolio Management · Mixed Executive & Operator Audience · Simulated Walkthrough*

**1. Overview**

This is the presenter's script for a 60-minute, five-act demonstration of an AI-enabled EPMO. It follows the narrative arc of the 5 Acts of SPM Transformation and demonstrates the 7 Pillars of AI-Enabled SPM through a simulated (non-production) interactive prototype.

Objective: move a mixed exec + operator audience from shared anxiety (“can we trust this data?”) through a hands-on look at statistical rigor, to a value story leadership can act on.

**A note on the name:** *“stochastic” is a real statistics term — it means governed by probability rather than fixed rules, the opposite of a guess. It won't be familiar to everyone in a mixed exec + operator room, so it's defined in plain language on the opening slide and again verbally in the Opening Line below, before the Framework Precursor begins. Don't assume the audience already knows it.*

**Appendix B — Anticipated Questions**

**“Is this connected to our real data, or is this a mockup?”**

Be direct: this is a simulated environment built to demonstrate the methodology end-to-end. A production build would connect to the same source systems already in use today (PPM tool, Jira/ADO, financial systems) — the statistical layer is what's new, not the data plumbing.

**“How much historical data do we need before Monte Carlo / SPC / regression are reliable?”**

Answer honestly and directionally rather than with a hard number: control limits and bias regression improve with more history, but Monte Carlo can run against estimated variance from day one and tighten as real delivery data accumulates. Offer a follow-up conversation with the data/analytics lead rather than committing to a specific threshold live.

**“Does this replace our PMO analysts?”**

No — it removes the manual assembly work (Act II) so analysts spend their time on judgment (Pillar 5, Pillar 7), not on the mechanics of forecasting.

**“What's the governance model for the automated triggers (Pillar 6)?”**

Automated workflows surface a flag and route it to a human decision-maker — they don't take action unilaterally. Useful to state explicitly if the room raises a control-and-governance concern.
