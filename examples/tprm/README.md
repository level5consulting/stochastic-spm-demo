# Example: Tributary (third-party risk, TPRM)

A worked example of a demo built with the Stochastic SPM Demo Kit structure, in a different domain: an AI-enabled early warning system for third-party risk, told through a fictional medical device maker (Halvern Medical) with a critical sterilization supplier in trouble.

**Live demo room:** https://level5consulting.github.io/stochastic-spm-demo/tprm/ (19-minute recording with chapters, the clickable prototype, slides, and files).

| Path | What it is |
|---|---|
| `app/index.html` | Tributary, the clickable prototype (open in a browser) |
| `deck/Tributary_Demo_Deck.pptx` | 7-slide deck with speaker notes |
| `deck/build_deck.js` | pptxgenjs source for the deck |
| `script/pre-read.md` | The fictional company, its people, and the discovery recap |
| `script/full-script.md` | Open, five acts and close, with stage directions |

All companies, people, suppliers and figures are fictional and illustrative. Role-play parts are cast from volunteers in the room. Content: CC BY 4.0, code: MIT, as for the rest of this repository.
